# Fjordvær

A 3D weather app. A small fjord landscape acts out the forecast for any place: clouds, rain, snow, fog, lightning, wind and the real sun and moon position.

- 48-hour time-lapse, 10-day forecast and a details panel (wind with Beaufort force, pressure trend, UV, air quality, daylight and the sun's path)
- Live forecasts from [Open-Meteo](https://open-meteo.com) (CC BY 4.0), loaded in the browser with no API key
- Everything is in `index.html`; 3D by three.js r128

Live at https://w1zman.github.io/fjordvaer/
